Generate Dynamic Open Graph with Next.js 14

November 2023 5 min read Next.js · SEO · Open Graph

One powerful way to enhance your website's shareability on social media is dynamic Open Graph meta tags. Every link you share renders a custom image and title instead of a blank preview. In this guide, we'll build this with Next.js 14 — from the ImageResponse edge route to the metadata object that wires it all together.

Exciting Times for Next.js Enthusiasts

Next.js 13 brought stability to the App Router along with a wave of new approaches to problems developers had been solving the same way for years. One of the biggest changes: SEO. The old Head.tsx pattern is gone, replaced by a type-safe metadata API that opens up capabilities the old approach could never support — including dynamically generated images.

open graph

Introduction: Understanding Open Graph

Before diving into code, let's understand what we're building for. Open Graph is a protocol developed by Facebook that standardizes how metadata is embedded in web pages so that social platforms — Facebook, Twitter/X, Slack, iMessage — can render a rich preview when a link is shared. Without it, shared links either show a blank card or grab whatever first image the scraper finds.

"Have you ever posted a link and seen a perfectly tailored image and title appear? That's Open Graph at work — and with Next.js 14 you can generate those images dynamically for every single page."

Implementing Dynamic Open Graph with Next.js

Let's build this from scratch. We'll create an API route using Next.js's ImageResponse to generate a custom OG image from any title, then wire it up via the metadata export.

💡 Tip

Drop a .ttf font file into public/fonts/. The OG route fetches it at request time using a relative URL from import.meta.url — no static imports, no bundler magic.

Step 2: Implement the Dynamic Open Graph Route

Create src/app/api/og/route.tsx. This route accepts a title query parameter and returns a 1920×1080 PNG, rendered from JSX at the CDN edge:

jsx 
// Import required modules and constants
import { ImageResponse } from "next/og";
import { NextRequest } from "next/server";

// Route segment config
export const runtime = "edge";

// Define a function to handle GET requests
export async function GET(req: NextRequest) {
  // Extract title from query parameters
  const { searchParams } = req.nextUrl;
  const postTitle = searchParams.get("title");

  // Fetch the Outfit font from the specified URL
  const font = fetch(
    new URL("../../../../public/fonts/outfit-semibold.ttf", import.meta.url),
  ).then((res) => res.arrayBuffer());
  const fontData = await font;

  // Create an ImageResponse with dynamic content
  return new ImageResponse(
    (
      <div
        style={{
          height: "100%",
          width: "100%",
          display: "flex",
          flexDirection: "column",
          alignItems: "flex-start",
          justifyContent: "center",
          backgroundImage: `url(http://localhost:3000/og-bg.png)`,
        }}
      >
        <div
          style={{
            marginLeft: 190,
            marginRight: 190,
            display: "flex",
            fontSize: 140,
            fontFamily: "Outfit",
            letterSpacing: "-0.05em",
            fontStyle: "normal",
            color: "white",
            lineHeight: "120px",
            whiteSpace: "pre-wrap",
          }}
        >
          {postTitle}
        </div>
      </div>
    ),
    // ImageResponse options
    {
      width: 1920,
      height: 1080,
      fonts: [
        {
          name: "Outfit",
          data: fontData,
          style: "normal",
        },
      ],
    },
  );
}
  • Import ImageResponse from next/og and NextRequest from next/server
  • Set runtime to "edge" — runs at CDN nodes, not a full Node.js server
  • Extract the title from searchParams
  • Fetch your font file as an ArrayBuffer (required by ImageResponse)
  • Return new ImageResponse() with a JSX layout and font config
⚠️ Warning

The backgroundImage in the JSX uses http://localhost:3000/og-bg.png — this only works locally. For production, replace it with your deployed domain URL, or base64-encode the image and inline it instead.

Step 3: Test Your Dynamic Open Graph Route

Start the dev server and navigate to:

http://localhost:3000/api/og?title=YourDynamicTitle

Replace YourDynamicTitle with any string. You should see a generated PNG in the browser with your title rendered using the loaded font.

Visiting an API route in the browser to see a PNG render in real time. Genuinely one of the more satisfying things Next.js lets you do.

Step 4: Implement the Dynamic Open Graph Meta Tags

Next.js 14 uses a metadata export in layout.tsx or page.tsx to handle all SEO attributes. For static pages, export it as a constant:

jsx 
import { Metadata } from 'next'; // if using TypeScript

export const metadata: Metadata = {
  openGraph: {
    title: 'Next.js',
    description: 'The React Framework for the Web',
    url: 'https://nextjs.org',
    siteName: 'Next.js',
    images: [
      {
        url: 'http://localhost:3000/api/og?title=Next.js', // Dynamic og route
        width: 800,
        height: 600,
      },
      {
        url: 'http://localhost:3000/api/og?title=Next.js', // Dynamic og route
        width: 1800,
        height: 1600,
        alt: 'My custom alt',
      },
    ],
    locale: 'en_US',
    type: 'website',
  },
};


export default function Page() {}

That object generates the following <meta> tags in the HTML output:

<meta property="og:description" content="The React Framework for the Web" />
<meta property="og:url" content="https://nextjs.org/" />

<meta property="og:locale" content="en_US" />
<meta property="og:image:url" content="http://localhost:3000/api/og?title=Next.js" />
<meta property="og:image:width" content="800" />
<meta property="og:image:height" content="600" />
<meta property="og:image:url" content="http://localhost:3000/api/og?title=Next.js" />
<meta property="og:image:width" content="1800" />
<meta property="og:image:height" content="1600" />
<meta property="og:image:alt" content="My custom alt" />
<meta property="og:type" content="website" />
💡 Tip

For dynamic pages (blog posts, product pages), use generateMetadata() instead — it's async and receives the route params, so you can fetch the post title and inject it directly into the OG image URL query string.
