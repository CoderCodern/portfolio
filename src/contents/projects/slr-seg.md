NashTech Vietnam · Jan 2026 – Present · Team size: 20+

A microservice-based transaction management application used to manage core business entities within a larger distributed system. The solution follows Clean Architecture principles, with a separated backend and frontend, and supports API-driven workflows, validation, and persistence through SQL Server.

## Contributions

- Developed and maintained backend services using .NET 10, ASP.NET Core, and MediatR
- Designed and extended the frontend using React 19, Vite, and TypeScript
- Integrated frontend and backend through RESTful APIs with consistent request/response validation and error handling
- Applied Clean Architecture across Core, Application, Infrastructure, API, and ClientApp layers
- Worked with Entity Framework Core and SQL Server for data persistence, model configuration, and migrations
- Supported cross-service interactions as part of a broader microservices ecosystem
- Contributed to unit-test-friendly code structure and maintainable feature modules

## Stack

- .NET 10 / ASP.NET Core Web API / MediatR
- Entity Framework Core / SQL Server
- React 19 / TypeScript / Vite / Tailwind CSS
- Clean Architecture (Vertical Slicing)
- REST APIs
