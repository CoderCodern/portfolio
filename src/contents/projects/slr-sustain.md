NashTech Vietnam · Oct 2025 – Dec 2025 · Team size: 20+

An ERP platform for project lifecycle management, contract tracking, and integration with Deltek Vantagepoint (VP). The project is built on a monolithic, well-structured architecture, following clean code principles and incorporating data warehousing for analytics and reporting.

## Contributions

- Developed and maintained backend services using .NET Core and .NET Web API
- Implemented core modules for project synchronization with VP, contract management, and workflow logic
- Built and integrated frontend components using ReactJS
- Designed and executed unit tests to ensure system correctness and reliability
- Contributed to the Data Warehouse architecture, supporting business intelligence and reporting needs
- Collaborated in sprint planning, API design, and system architecture discussions

## Stack

- .NET Core / .NET Web API
- ReactJS / TypeScript
- SQL Server / Data Warehouse
- Clean Architecture
