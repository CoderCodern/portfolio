Windsoft Vietnam · Dec 2023 – Dec 2024 · Team size: 10

An e-commerce MiniApp on Zalo that offers services such as booking, ride-hailing, delivery, and food ordering — focusing on user convenience and integration of various service modules.

## Contributions

- Designed scalable backend APIs and supported cross-platform data synchronization
- Built admin dashboard features and managed versioning for multiple service modules
- Integrated 3rd-party services like ZaloPay, Goong Maps, and ElasticSearch
- Handled CI workflows including code merging, deployment, and release versioning

## Stack

- ASP.NET MVC / ASP.NET Web API
- SQL Server
- ElasticSearch / ZaloPay / Goong Maps
