NashTech Vietnam · Feb 2025 – Sep 2025 · Team size: 12+

An enterprise finance and insurance system for a UK client, responsible for integrating data with government APIs (e.g. Justice) and managing policy-related operations. The project follows a microservices architecture with a strong focus on performance, scalability, and clean design.

## Contributions

- Designed and implemented REST APIs using .NET Minimal API and Clean Architecture (Vertical Slicing)
- Integrated and mapped third-party services (e.g. Justice API) to internal models with frontend compatibility in mind
- Wrote comprehensive unit tests, functional tests (ReqnRoll), and performance tests using K6 and BenchmarkDotNet
- Actively participated in Agile ceremonies, code reviews, and service integration discussions
- Collaborated with the frontend team to ensure API contract alignment and smooth validation

## Stack

- .NET Core / .NET Web API / Minimal API
- Angular / TypeScript
- Docker / Microservices
- K6 / ReqnRoll / BenchmarkDotNet
- Clean Architecture (Vertical Slicing)
