# Accent Colors by Episode

Each episode in the series gets a distinct accent color. Pick based on episode number or topic.

| Episode / Theme           | Accent color | CSS value  | Dim (background tint) |
|---------------------------|--------------|------------|------------------------|
| Episode 01 / Installation | Amber        | `#e8a84c`  | `#3d2c12`              |
| Episode 02 / CLAUDE.md    | Purple       | `#c9b1f5`  | `#1e1529`              |
| Episode 03 / Skills       | Green        | `#4caf7d`  | `#122a1e`              |
| Episode 04 / Subagents    | Blue         | `#79c0ff`  | `#0d1f2d`              |
| Episode 05 / Hooks        | Orange-red   | `#f0856a`  | `#2d1510`              |
| Episode 06 / Workflows    | Cyan         | `#56d4c8`  | `#0d2422`              |
| New / unassigned          | Amber (default) | `#e8a84c` | `#3d2c12`           |

Set `--accent` and `--accent-dim` in `:root` with the chosen values.
