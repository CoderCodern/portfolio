# Divider Label Rules

Every `<h2>` section must be preceded by a `.divider`. Extract a 1–3 word label from
the section heading — lowercase and short.

```html
<div class="divider"><span>the hierarchy</span></div>
<h2>Four Levels, One System</h2>
```

## Label Examples

| H2 heading                                    | Divider label      |
|-----------------------------------------------|--------------------|
| "The Mental Model Most People Get Wrong"      | `the mental model` |
| "Global vs Local — Where Your Skill Lives"    | `where it lives`   |
| "The Four Design Patterns"                    | `four patterns`    |
| "Honest Friction Points"                      | `friction`         |
| "What I Did Each Day"                         | `week one`         |
| "Bonus: Teaching Claude Who You Are"          | `bonus`            |
