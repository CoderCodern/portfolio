# H1 Italic Keyword Rule

Always wrap the most evocative or important word/phrase in `<em>` inside the `<h1>`.
This creates the accent-colored italic highlight effect.

## Good examples

```html
<h1>CLAUDE.md: The File That Gives Claude a <em>Memory</em>, a Soul, and a Spine</h1>
<h1>Skills: The <em>Passive Knowledge Layer</em> That Makes Claude Actually Good</h1>
<h1>Week One: Learning to <em>Stop Prompting</em> and Start Describing</h1>
```

## Bad examples

```html
<!-- Don't italicize technical terms or file names -->
<h1>How to Write a <em>CLAUDE.md</em> File</h1>

<!-- Don't italicize the first word or generic terms -->
<h1><em>Introduction</em> to Claude Code</h1>
```

## Rule

Pick the phrase that carries the most conceptual weight or emotional resonance —
not a proper noun, not a file name, not the first word.
